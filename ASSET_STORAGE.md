# Asset Storage Policy

Heavy source and generated media are stored in Google Drive.

Drive project folder:
https://drive.google.com/drive/folders/11R3HSowEWnplcueTDRrHfOEtrPKixIcl

Structure:
- `01_SOURCE_MEDIA/`: source clips, screenshots and references.
- `02_GENERATED_MEDIA/`: generated thumbnails, graphics and working renders.
- `03_DELIVERABLES/`: final exports and handoff packages.

GitHub keeps code, scripts, prompts, rules and manifests. New large binary media must go to Drive and be referenced from GitHub metadata.
